## Direction distilled from the set

The useful common ground is a warm neutral canvas, large but disciplined typography, sharp rectangular media, clear editorial rules, and project rows that reveal detail without turning every item into a floating card. Motion should support reading order and product discovery. The portfolio should remain faster, quieter, and more accessible than the most experimental references.
